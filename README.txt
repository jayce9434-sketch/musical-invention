KNOCK A BUG: OVERHAUL

This is the major rebuild of Knock a Bug. It is not a small Update 1 patch: the progression, flight loop, currencies, map rewards, art, run variety, and long-term goals were rebuilt around a roughly three-hour first-completion target.

CORE LOOP
- Time the KNOCK meter and launch your selected bug.
- Hold GLIDE or DIVE during flight to steer between four reward lanes.
- Collect Coins, Cells, Scrap, map pickups, and hidden Souvenirs.
- Smash objects, hit map gimmicks, clear run challenges, build Momentum, and open Field Capsules.
- Upgrade bugs, knockers, permanent stats, mutations, and run gadgets.
- Complete five contracts per map and work toward full Grand Run completion.

THREE CURRENCIES
Coins
- Main progression currency.
- Used for maps, bugs, knockers, bug training, and permanent upgrades.
- Every run pays Coins from distance and landing even if you miss every object.
- All four altitude lanes have pickup routes, so flying high no longer means flying above the economy.

Cells
- Mutation currency.
- Much easier to earn in the Overhaul.
- Earned from every completed run, route Cell pickups, contracts, Field Capsules, run challenges, mastery level-ups, distance milestones, Cell Surge events, Souvenirs, and the Cell Extractor gadget.

Scrap
- New third currency.
- Earned from smashed objects, route Scrap pickups, challenges, Field Capsules, payday gates, Souvenirs, and Scrap Rush events.
- Spent on Run Gadgets that change how future runs behave instead of simply adding another number multiplier.

RUN VARIETY AND RETENTION
- 25 Map Contracts: five per map.
- 15 permanent hidden Souvenirs: three per map.
- Random run challenges with Momentum streak rewards.
- Field Capsules after a set number of launches.
- Random run events: Golden Run, Low Gravity, Coin Storm, Scrap Rush, and Cell Surge.
- Four altitude reward routes: Ground, Mid, High, and Sky.
- Map-specific guaranteed payday gates that can be collected at any altitude.
- Mid-flight GLIDE/DIVE control with rechargeable Air Control energy.
- Bug Mastery progression and rewards.
- Completion Journey tracks maps, bugs, knockers, contracts, Souvenirs, challenges, and upgrade progress.

PROGRESSION TARGET
The economy is designed around a first full journey of about 2.5-3.5 hours for a normal player, with faster or slower completion depending on timing skill, route control, challenge luck, and upgrade choices. The goal is steady unlocks throughout the run rather than a short upgrade sprint followed by nothing to do.

CONTROLS
- KNOCK: stop the timing meter and launch.
- GLIDE: hold to rise or stay on higher routes.
- DIVE: hold to drop toward lower routes.
- Mega Knock / Air Boost / Coin Magnet / Ground Slam: active flight abilities with cooldowns.

OWNER PANEL
Open Settings -> Owner Panel and enter the configured owner code. It can grant Coins, Cells, or Scrap; unlock content; complete contracts; max upgrades; and reset data for testing.
